# SHN WayFinder demo

A responsive static recreation of the supplied SHN WayFinder screenshots.

## Run locally

Serve the `dist` directory with any static file server, for example:

```sh
python3 -m http.server 3000 --directory dist
```

Then open `http://localhost:3000/`.

Pages:

- `index.html` — homepage
- `faq.html` — FAQ list
- `directory.html` — directory shell (visual only; no search functionality)
- `map.html` — hospital map
